**Explicit advice:** Guide a competent user's actions toward a bounded outcome; allow judgment and different entry/exit points. Order actions coherently and move background/reference material off the action path.

**Adaptation/limits:** Use conditional research, drafting, and repair routes. This does not require four document types or a single rigid procedure.
