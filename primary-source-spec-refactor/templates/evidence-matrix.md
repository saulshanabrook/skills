# Evidence Matrix

| Knowledge unit | Claim or need | Primary project evidence | External method source | Freshness | Gap/risk | Action |
| --- | --- | --- | --- | --- | --- | --- |
|  |  |  |  | Current / stale / unverified |  | Preserve / rewrite / split / ask / defer |

## Evidence Rules

- Use exact paths, line numbers, test names, command names, issue/PR links, or accepted decision IDs.
- Mark command output with date, checkout, and whether it was rerun.
- Mark inferred claims explicitly.
- Do not turn a weakly evidenced claim into normative language.
